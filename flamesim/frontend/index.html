About FlameSim · NASA PSI Data & Interpolation Methodology

1. Data Source (NASA Physical Sciences Informatics — PSI): FlameSim is driven by experimental microgravity combustion records from NASA campaigns including Saffire I–VI, SoFIE (Solid Fuel Ignition and Extinction), BASS (Burning and Suppression of Solids), FLEX / Cool Flames Investigation, and SAME (Smoke Aerosol Measurement Experiment).

2. Prediction & Interpolation Method (predict.py): Inputs are normalized across a 5-dimensional space (O₂ mole fraction, log-scaled ventilation velocity, sample thickness, cabin pressure, and gravity level). Each numeric output is predicted independently using k-Nearest Neighbors Inverse-Distance-Weighted (IDW) interpolation ($k=3\text{–}4$) over only those experimental rows that report that specific output. Categorical outputs (combustion regime, optimal sensor, mitigation) use distance-weighted majority voting.

3. Physically-Inspired Heuristic Fallback & Model Limits: When an output column is completely unreported for a material, or when the user selects Custom Material, FlameSim falls back to an analytical microgravity combustion correlation (accounting for limiting oxygen index $\text{LOI}$, radiative quenching at $0\text{ cm/s}$, cool-flame transition around $\sim 600\text{ K}$, and high-velocity Damköhler blow-off) and explicitly tags the output as heuristic (low confidence).

PRELIMINARY ENGINEERING DISCLAIMER: Data-driven model v1 (interpolation on PSI/NASA experiments). Preliminary decision-support tool developed for the NASA Space Apps Challenge 2026 ("Flame in Freefall"). Not certified for operational spacecraft flight readiness decisions.
